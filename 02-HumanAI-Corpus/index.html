About this Project

This project constructs a corpus of human–AI interactions and analyzes differences in sentence structure between human-generated and AI-generated responses.


Dataset: tatsu-lab/alpaca — 52,000 instruction-following examples generated by OpenAI's text-davinci-003.


How to reproduce:


pip install datasets pandas nltk matplotlib


python download_data.py → python annotate.py → python analyze.py
